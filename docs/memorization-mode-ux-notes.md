# ملاحظات وضع التدريب على صفحة المصحف

تتفق أنماط تطبيقات التحفيظ الحديثة على إبقاء المستخدم داخل صفحة المصحف نفسها، مع إخفاء الآيات بدل نقله إلى قائمة منفصلة. النمط المستخدم هنا هو إظهار الآية وإخفاؤها مع تثبيت بنية الصفحة.

وضع التدريب الحالي يستخدم صفحة المصحف نفسها. يُخفى نص الآيات وتبقى علامات الآيات وبنية الصفحة. شريط التحكم يُظهر كل الآيات أو يخفيها، ويشغّل تلاوة الآية المحددة، ويغلق التدريب. لا يسجّل التطبيق صوت المستخدم ولا يقارن التسميع آليًا.

المراجع: [Tarteel على App Store](https://apps.apple.com/us/app/tarteel-ai-quran-memorization/id1391009396)، [Retain Quran على App Store](https://apps.apple.com/pk/app/retain-quran-learn-memorize/id1624792039)، و[مراجعة تطبيقات التحفيظ](https://studentsofquran.com/my-top-5-choices-for-quran-memorization-apps/).
