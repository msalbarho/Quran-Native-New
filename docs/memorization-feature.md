# التدريب والحفظ

التدريب شاشة مستقلة من الصفحة الرئيسية وشريط التنقل. تستخدم صفحة المصحف نفسها، وتخفي نص الآيات مع إبقاء علامات الآيات وبنية الصفحة. لا يطلب التطبيق الميكروفون، ولا يسجّل صوت المستخدم، ولا يحوّل الكلام إلى نص.

| الإجراء | النتيجة |
| --- | --- |
| فتح التدريب | تُخفى نصوص الآيات على الصفحة الحالية. |
| النقر على آية مخفية | تُظهر تلك الآية. |
| إظهار الكل / إخفاء الكل | يُظهر نصوص الصفحة أو يعيدها إلى الإخفاء. |
| استماع | يشغّل تلاوة الآية المحددة بالقارئ الحالي. |
| إغلاق | يعود إلى شاشة القراءة. |

في أول فتح يظهر شرح قصير من ثلاث خطوات: اقرأ الآية ثم أخفها، سمّعها من حفظك، ثم أظهرها وراجع بنفسك. يمكن تخطي الشرح، ولا يعود بعد ذلك.

لا توجد مقارنة آلية للنص، ولا نتيجة مئوية، ولا تسجيل مؤقت. المراجعة يدوية بعد إظهار الآية.
